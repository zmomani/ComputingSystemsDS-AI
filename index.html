Computing Systems for Data Science and Artificial Intelligence

A 16-week, project-driven course from transformers to agents: LLMs, Mixture of Experts, ReAct, multi-agent systems, MCP, Large Action Models and diffusion — built around a multi-agent research assistant that competes live in Week 15.

Each lesson has the explanation on the left and a panel on the right. ▶ Try it runs an example in a live Python editor inside your browser — nothing to install. ▶ Display opens an animation of the concept you are reading about. ⧉ Open in Codespaces opens the course environment for everything else. Course overview

What you'll learn

Transformers, LLMs, Mixture of Experts, AI agents and ReAct, multi-agent systems, Model Context Protocol (MCP), Large Action Models (LAMs) and diffusion models.

What you'll build

NER systems, RAG pipelines, LangGraph agents, multi-agent workflows, LAM applications and generative-AI projects, culminating in a multi-agent research assistant.

Technologies

Python 3.12+, PyTorch, Hugging Face, LangChain & LangGraph, OpenAI API, Ollama, Playwright, VS Code.

Who should take it

University of Petra students in Data Science and AI degrees interested in LLMs and agents. Basic Python is recommended.

Test your knowledge

1. What mechanism lets transformers process sequences effectively?

A) RecurrenceB) Self-attentionC) ConvolutionD) Pooling

Self-attention lets every token look at every other token in parallel — see the self-attention animation in Week 1.

2. In ReAct, what does the cycle consist of?

A) Input, Process, OutputB) Thought, Action, ObservationC) Encode, Decode, GenerateD) Query, Key, Value

Reasoning traces interleaved with tool actions and their observations — see the ReAct loop animation in Week 9.

3. What is the main advantage of MoE models?

A) Smaller model sizeB) Better training dataC) Sparse activation reduces compute while maintaining performanceD) Simpler architecture

Only the top-k experts run for each token — see the MoE router animation in Week 7.

Assessment & grading

Weights

  • Assignments — 10%
  • Project (rubric-based) — 20%
  • Midterm (Week 8, covers Weeks 1–7) — 30%
  • Final (Week 16, all material; emphasis on agents, ReAct, multi-agent, MCP, LAMs, diffusion) — 40%

Weekly workload

3 hours on campus (theory, demos, hands-on) plus 4–6 hours of self-study. Teams of 2–3; every week has a project milestone.

Resources

Required software

Python 3.12+, PyTorch, Hugging Face Transformers, LangChain & LangGraph, Ollama, VS Code. Keep API keys in a .env file and never commit them.

Hardware

Minimum: 8 GB RAM, i5, 50 GB storage, webcam.
Recommended: 16 GB RAM, i7/Ryzen 7, dedicated GPU, 100 GB SSD.
